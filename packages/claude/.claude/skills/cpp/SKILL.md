Commit the uncommitted changes, push them, and create a PR. Create a branch first if you're in the default branch. Write the commit message and PR title/body based on the language used in the recent commit messages in this project. When needed, break it down into 2+ commits. If there is a PR that's already open for this branch and you just pushed new commits, check the PR to see if the title/body should be updated. If so, update.
