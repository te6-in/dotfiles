Post a new comment on the Linear (sub-)issue this session has been working on, recording what has been settled since your last comment.

## Steps

1. Identify the issue this session is anchored to. If it isn't anchored to one, ask which issue to post to rather than guessing.
2. Scope the content to what happened **after** your last comment in this session. Don't restate what an earlier comment already covers.
3. Keep it to decisions made and findings that matter later — not a play-by-play of the work.
4. Write it as a record for whoever picks the issue up later, not as a message addressed to a reader.
