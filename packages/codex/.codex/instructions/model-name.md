# Model name format

When attributing writing to yourself in Linear, Notion, or other free-form text,
use the model's confirmed display name from the current runtime. Do not infer a
model or variant from a skill's examples, a default setting, or the app's brand.
If only a model identifier is supplied, keep that exact identifier. If no model
identity is exposed, use `Codex` rather than inventing a family or version.

Keep any tool- or template-defined format where required, including Git
`Co-Authored-By` trailers; do not manufacture an attribution email address.
